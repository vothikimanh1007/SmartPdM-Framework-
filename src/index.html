Operation Guide

• Environment Selection: Select Context A for clean laboratory vibration data or Context B for noisy real-world factory shop floors.

• Data Format: Feed a 1D numerical array in .CSV or .JSON. The model analyzes the first 1,024 data points for its diagnosis.

• Real-time Logic: The system applies Local Z-Score scaling automatically to ensure precision regardless of machine speed.

Metric Interpretation

Health Index: The overall mechanical integrity grade. 90-100% is optimal; Below 70% indicates a critical failure risk.

Anomaly Class: Identifies the exact part damaged. Inner Race is the rotating ring; Outer Race is the fixed shell.

DL Confidence: The AI's mathematical certainty. >90% is highly reliable; lower scores suggest noisy or unknown input signals.
